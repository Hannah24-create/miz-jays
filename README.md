# Miz Jays Beauty Salon Website

A full-stack beauty salon website built with the MERN stack
(MongoDB, Express, React, Node.js)

## About

Miz Jays is a beauty salon located at Lakeside Community 5,
Accra. This website showcases their services, portfolio and
products — with WhatsApp integration for bookings and orders.

## Technologies Used

- MongoDB — Database
- Express.js — Backend framework
- React.js — Frontend
- Node.js — Runtime environment
